# Radar Sem Site

Ferramenta estática que lista comércios sem site (dados do OpenStreetMap) com botão de WhatsApp.

Sem build: `index.html`.

## Live interativa

Em `live-interativa/` há um overlay para lives do TikTok em que presentes reais disparam efeitos e baús de prêmios. Veja `live-interativa/README.md`.
